# Portfólio — Letícia Ambrosio

Site estático para GitHub Pages, desenvolvido com HTML, CSS e JavaScript, sem bibliotecas externas.

## Publicação

1. Crie um repositório **público** chamado `SEUUSUARIO.github.io` no GitHub (troque SEUUSUARIO pelo nome real da conta).
2. Na página do repositório, escolha **Add file → Upload files** e envie `index.html`, `style.css` e `script.js` (extraia o ZIP antes). Confirme com **Commit changes**.
3. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch** e escolha `main` e `/(root)`. Salve.
4. Aguarde alguns minutos e visite `https://SEUUSUARIO.github.io/`.

## Personalização

- `index.html`: substitua o link genérico `https://www.linkedin.com/` pelo endereço do seu perfil.
- `index.html`: acrescente um e-mail profissional, caso deseje, na seção Contato.
- `index.html`: substitua os cartões planejados por projetos concluídos e inclua links para seus repositórios e capturas reais.
- `style.css`: altere as cores no seletor `:root`.

Os números do painel inicial são apenas **ilustrativos**. Os projetos estão marcados como **planejados** para não sugerir experiência ou entregas inexistentes.

Não publique dados reais de clientes ou versões integrais de planilhas que pretende comercializar.
